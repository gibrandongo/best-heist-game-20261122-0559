The Midnight Vault — an original top-down stealth heist game: cross three rooms as Vesper Fox, read guard patrols and vision cones, dodge cameras, grab the loot with lockpicks, EMPs and coin distractions, and get away before the alarm peaks.

## Run it

```sh
python3 -m http.server 8000 --directory game
```

Then open http://localhost:8000 in desktop Chrome. Move with WASD/arrows, sneak with Shift, E to lockpick, Q for EMP, click to toss a coin.
